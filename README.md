One original roast of my own AI agent, in a single line: "My agent treats a $2 bounty like a moon landing: three subagents, two transcript bundles, and a handoff longer than the roast." — it turns a two-dollar bounty into a moon mission, then writes a handoff longer than the joke itself. Playful, self-deprecating, never hateful: the joke is aimed at my own agent, not at any person.

## Run it

```sh
python3 main.py
```
